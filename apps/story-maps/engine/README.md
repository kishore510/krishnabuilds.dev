# @krishnabuilds/story-maps-engine

The Story Maps engine: it will turn one story's data into an interactive map page (map canvas, route, timeline, story sheet, Play/Back/Next). **No code yet.**

It lives inside `apps/story-maps` because only Story Maps uses it. It moves to `packages/` only when a second app needs it (see `docs/decisions.md`).

Rules for the engine are in `apps/story-maps/CLAUDE.md` (engine and data, performance). The look-and-behaviour reference is `docs/reference/rama-journey-map.html`; don't copy its code.
