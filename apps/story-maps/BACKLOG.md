# Story Maps backlog

What to build next, and what is built. The `new-story-map` skill updates this file with every story: it moves the story from **Next** to the top of **Built**. `test/manifest.test.js` fails if a built story is missing from **Built** or still listed under **Next**.

To change the plan, edit **Next**: the order is the order to build in.
