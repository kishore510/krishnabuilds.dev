# Rama’s Journey

Status: built. Rama’s route from Ayodhya to Lanka and home in 16 chapters, following the Valmiki Ramayana and the places tradition links to it, with the kingdoms the epic names.

- `story.json`: the story data (places, chapters, routes, timeline, kingdoms). It uses the `south-asia` basemap and the shared art library.
- Source: tradition. The story text, places and kingdoms come from the owner's reference build, `docs/reference/rama-journey-map.html`.
