# Reference files

Files here are **reference only**. They are not built, deployed or linked from any app.

- `tennis-prototype.html`: prototype for the Arcade tennis game.
- `rama-journey-map.html`: the look-and-behaviour reference for Story Maps (`apps/story-maps`), kept exactly as it was made. It breaks two Story Maps rules: it loads Google Fonts, and it defines an SVG blur filter (`feGaussianBlur`, unused). **Don't copy its code into the Story Maps engine**; build the engine from the rules in `apps/story-maps/CLAUDE.md` and use this file only to see how the map should look and behave.
